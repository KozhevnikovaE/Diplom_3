# Проект: UI-тесты для Stellar Burgers

Автотесты для проверки веб-приложения Stellar Burgers.

---

## Реализованные сценарии

### Конструктор
- Переход по клику на «Конструктор» (с возвратом с ленты заказов)
- Переход по клику на «Лента заказов» (проверка через счётчик)
- Открытие модального окна при клике на ингредиент
- Закрытие модального окна по крестику
- Увеличение счётчика ингредиента при добавлении в заказ (Drag & Drop)

### Лента заказов
- Увеличение счётчика «Выполнено за всё время» после создания заказа
- Увеличение счётчика «Выполнено за сегодня» после создания заказа
- Отображение номера заказа в разделе «В работе»

---

Для запуска тестов в Firefox требуется установка браузера в стандартную папку: C:\Program Files\Mozilla Firefox

## Структура проекта

- `helpers/` — вспомогательные функции (API-запросы, генерация данных)
- `locators/` — локаторы элементов по страницам
- `pages/` — Page Object классы (действия на страницах)
- `tests/` — тесты (конструктор, лента заказов)
- `drivers/` — драйверы браузеров (Chrome, Firefox)
- `conftest.py` — фикстуры (драйверы, API-клиент, авторизация)
- `requirements.txt` — зависимости

---

## Запуск автотестов

Установка зависимостей:
pip install -r requirements.txt

text

Запуск всех тестов:
pytest tests/ -v

text

Запуск с Allure-отчётом:
pytest tests/ --alluredir=allure-results -v
allure generate allure-results -o allure-report --clean
allure open allure-report

text
